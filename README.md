# corcaAds_android_plugins
'corcaAds_android_plugins' is a plugins that help develop 'corcaAds' Android services.  
The plugins can be divided into three main categories.

- `corcaAds_analytics`: **Collects logs** for event analysis of corcaAds projects.
- `corcaAds_placement`: It is a plugin where you can receive **products recommended by AI** based on user information.
- `corcaAds_agent`: Provides an **AI assistant** that allows users to talk directly.
