#  corcaAds_analytics 

Android plugin that collects logs for event analysis of corcaAds projects.

To learn more about corcaAds, please visit the [corcaAds website](https://docs.corca.dev/receiver-api/introduction)

</br>

## Usage

**onImpression example:**
```kotlin
corcaAdsAnalytics.onImpression(
  option = logOption
)
```

**onClick example:**

```kotlin
corcaAdsAnalytics.onClick(
  option = logOption
)
```
</br>

## Features


| Event | Function |
| --- | --- |
| impression | corcaAdsAnalytics.onImpression(option) |
| click | corcaAdsAnalytics.onClick(option) |


To learn more about usage of plugin, please visit the [corcaAdsAnalytics Usage documentation.](https://docs.corca.dev/receiver-api/introduction)
